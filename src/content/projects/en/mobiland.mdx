mobiland is a prototype that brings products from different furniture brands into one site. Products can be compared by brand, category and price, and an AI assistant picks pieces based on your room, budget and style.

The brands and products are fictional and nothing is sold. The catalogue lives in a single file, and the rest of the site only uses that file’s functions, so a real database can replace it later without touching the pages.

## Every product in one place

The product list can be filtered by category and brand, and products can be saved to favourites. Each card shows the dimensions and how many sellers carry it.

## One product, several sellers

Sellers offering the same product are compared in one table with price and delivery details, and the best deal is highlighted. The product page also lists dimensions, material and style, plus similar products from other brands.

<Figure src={detail} caption="Product page · sellers and prices in one table" />

## An assistant that builds a room within budget

The assistant understands requests like “a living room set for ₺40,000” and picks a sofa, coffee table and lighting from different brands. To build a set, it tries every combination of products for each piece. Among those that fit the budget it picks the most complete one that mixes the most brands. If nothing fits, it suggests the cheapest option and says how far over budget it goes.

<Figure src={assistant} caption="AI assistant · a living room set built for ₺40,000, with ₺1,950 to spare" />

## The AI side

The assistant runs on Google Gemini. The API key stays on the server, and the catalogue is sent along with the system prompt. The model has to answer in a fixed JSON schema (structured output), so its reply can be turned into product cards safely.

If a model on the free tier is busy, the next one is tried. Without a key, or if something fails, a rule-based demo assistant takes over. Message length, chat history and request rate are limited to prevent abuse.
